## What it Daftar

Daftar is a single HTML file that runs entirely in your browser. Open it, write, and your notes stay on your own device. It is built for people who write in both English and Persian — each note can have its own writing direction independent of the interface language.

There is no account, no analytics, no ads, no cloud service. The optional AI connects directly to a local Ollama server on your own computer; nothing leaves the machine unless you deliberately send it.

---

## Features

- **Bilingual interface** — complete English and Persian (RTL) modes, switched independently from note direction
- **Per-note direction** — Auto, LTR, RTL for each note
- **Markdown with live preview** — write Markdown, see it rendered; copy as readable text or as Markdown
- **Snapshots and recovery** — version history, emergency draft recovery, archive, and recoverable trash
- **Local AI (optional)** — connect to Ollama for summarize, title-and-organize, polish, key points, translation, and custom instructions
- **Backup and export** — full JSON backup, all notes as Markdown, current note as plain text
- **Themes and palettes** — five palettes in light and dark modes, focus mode, adjustable text and line spacing
- **Works offline** — no external fonts, scripts, or trackers once the file is open
