## این چیست

ابزار Daftar یک فایل HTML واحد است که کاملاً در مرورگر شما اجرا می‌شود. آن را باز کنید، بنویسید، و یادداشت‌هایتان روی دستگاه خودتان می‌مانند. برای کسانی ساخته شده که به فارسی و انگلیسی می‌نویسند — هر یادداشت می‌تواند جهت نوشتار مستقل خودش را داشته باشد، جدا از زبان رابط.

هیچ حساب کاربری، تحلیل‌گر، تبلیغ یا سرویس ابری‌ای وجود ندارد. هوش مصنوعی اختیاری مستقیماً به یک سرور محلی Ollama روی رایانهٔ خودتان متصل می‌شود؛ تا وقتی آگاهانه نفرستید، چیزی از دستگاه بیرون نمی‌رود.

## امکانات

- **رابط دوزبانه** — حالت کامل انگلیسی و فارسی (RTL)، مستقل از جهت هر یادداشت
- **جهت مستقل هر یادداشت** — خودکار، LTR، RTL
- **Markdown با پیش‌نمایش زنده** — با Markdown بنویسید و خروجی پردازش‌شده را ببینید؛ کپی به‌صورت متن خوانا یا Markdown
- **نسخه‌ها و بازیابی** — تاریخچهٔ نسخه‌ها، بازیابی پیش‌نویس اضطراری، بایگانی و زباله‌دان قابل‌بازیابی
- **هوش مصنوعی محلی (اختیاری)** — اتصال به Ollama برای خلاصه‌سازی، عنوان و دسته‌بندی، ویرایش، نکات کلیدی، ترجمه و دستور دلخواه
- **پشتیبان و خروجی** — پشتیبان کامل JSON، همهٔ یادداشت‌ها به‌صورت Markdown، یادداشت جاری به‌صورت متن ساده
- **پوسته و پالت** — پنج پالت در حالت روشن و تاریک، حالت تمرکز، اندازهٔ متن و فاصلهٔ خط قابل‌تنظیم
- **آفلاین کار می‌کند** — پس از باز شدن فایل، هیچ فونت، اسکریپت یا ردیاب بیرونی ندارد
