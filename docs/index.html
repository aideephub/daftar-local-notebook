Connect Ollama

  1. Start Ollama and make sure at least one model is installed, for example gemma4.
  2. Keep the address at http://127.0.0.1:11434, then press Connect. Daftar reads models from /api/tags and sends requests to /api/chat.
  3. If Ollama works in Terminal but Daftar says “Failed to fetch,” allow browser origins once, fully restart Ollama, and try again:

Windows (Command Prompt, then fully restart Ollama)

setx OLLAMA_ORIGINS "*"

macOS (Terminal, then fully restart Ollama)

launchctl setenv OLLAMA_ORIGINS "*"

Linux (when launching Ollama yourself)

OLLAMA_ORIGINS="*" ollama serve
The wildcard lets browser pages on this computer request Ollama while it is running. Keep Ollama bound to 127.0.0.1 so it is not exposed to other devices, and only use Daftar with pages you trust.
